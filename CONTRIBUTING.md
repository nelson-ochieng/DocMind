# Contributing

Open an issue for proposed changes. Until a project license is selected, discuss contribution permissions with the maintainer before submitting code.

Use Python 3.11 and a virtual environment, install requirements-dev.txt, and run python -m pytest -q. Use synthetic documents or fixtures with explicit redistribution rights. Never commit private documents, databases, models, tokens or build output.

Keep changes focused. Include regression tests for fixes, describe the environment and distinguish mocked tests from live Ollama or Windows tests. Document any changes to privacy boundaries or dependencies. Submit a pull request with a summary and test results.
